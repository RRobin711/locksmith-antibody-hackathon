- **fab**: pooled within-variant variance 0.00103; across-panel variance 0.02918; **reliability r = 0.965**

Reliability here is `1 - sigma2_within / sigma2_observed` — an intraclass correlation. It is estimated from only 3 variants, chosen to span the range, so it assumes seed noise is roughly constant across the quality range. A poly-Gly design plausibly has larger seed variance than pembrolizumab, which would make this an optimistic average.

### 1.1 The reliability asymmetry, and what it costs

**Fv ipSAE is a far noisier measurement than Fab ipSAE: r = 0.61 vs 0.96.** This is the under-constrained VH/VL elbow showing up as measurement error. A bare Fv has nothing to clamp the relative orientation of the two variable domains, so a diffusion model samples genuinely different elbow angles between seeds; the constant domains in a Fab pin it. The project predicted this qualitatively when it chose Fv-screen/Fab-confirm. Measured, it undermines the screen rather than supporting it.

Averaging over seeds would recover reliability (Spearman-Brown, `r_k = k*r / (1 + (k-1)*r)`) -- but it has to be paid for:

| Fv seeds | Fv reliability | Fv wall clock | vs one Fab fold |
|---|---|---|---|
| 1 | 0.607 | 92 s | 0.74x |
| 2 | 0.756 | 185 s | 1.47x |
| 3 | 0.823 | 277 s | 2.21x |
| 4 | 0.861 | 370 s | 2.94x |

- One Fab fold measured at **126 s**, one Fv fold at **92 s** (mean over the panel; both include ~100 s of fixed per-invocation overhead).
- **No number of Fv seeds reaches the Fab's reliability** (r_inf = 1.0 asymptotically, but 0.96 needs k > 8 and 5.9x the Fab cost already).

**So the cheap screen is not cheap.** Even at 2 seeds the Fv costs more wall clock than the Fab it was supposed to save, and is still less reliable. The 2.5x residue-count saving does not survive contact with the fixed per-fold overhead and the elbow noise.

## 4. Gate 1d — is the Boltz/AF2 ipSAE gap a scale offset or deserved?

### 4.1 AlphaFold2 could not be run on the designs at all

All 7 ColabFold folds used `--msa-mode single_sequence`, because the default mode uploads the query to the **public MMseqs2 server** and a designed sequence must never go there. Every one of them failed to build a complex:

| | AF2 single-sequence | AF2 with MSAs (same complex) |
|---|---|---|
| pLDDT | 37.1 | 94.4 |
| pTM / ipTM | 0.231 / 0.111 | 0.917 / 0.891 |
| ipSAE | 0.000 | 0.654 |
| DockQ | 0.017 | 0.690 |
| min inter-chain distance | **0.5-0.9 A** (atoms interpenetrating) | normal |

This is a real property of AlphaFold2, not a pipeline fault: AF2 derives its structural signal from co-evolution in the MSA, and without one it does not fold complexes. Boltz-2 is far more robust single-sequence, which is exactly why the antibody chains can be given `empty` alignments in the first place.

**Consequence: G1d cannot be discharged on designed sequences under the current constraints.** AF2 needs MSAs; MSAs need either the public server (forbidden for designs) or a local sequence database (not installed). This is a cost decision, not something to engineer around -- see the session doc for the three options.

### 4.2 What can still be said, using the panel as a calibration curve

The one legitimate AF2-with-MSA point is pembrolizumab itself, whose sequence is published, so the server was a fair use. The panel now supplies something the previous single-point comparison lacked: a **Boltz ipSAE-vs-DockQ curve**. So ask the question properly -- *given a structure of DockQ 0.690, what ipSAE would Boltz have reported?* If AF2's 0.654 matches that prediction, the gap was fully explained by structure quality and there is no scale offset. If AF2 sits below it, the residual is the offset.

- Boltz-2 Fv calibration curve: `ipSAE = +0.421 +0.527 x DockQ` (n=14, R2=0.919, residual sd 0.043)
- At AF2's DockQ of **0.690**, Boltz's curve predicts ipSAE **0.784**
- AF2 actually reported **0.654** -> residual **-0.131** = **3.1 residual sd**

So the AF2 point sits **3.1 residual sd from the Boltz curve**, which is a genuine offset beyond what structure quality explains.

**Weight this appropriately: n=1 for AF2.** One point cannot establish an offset, only fail to find one. What has improved is the reference -- the comparison is now against a 14-point calibration curve with a measured residual spread, instead of against a single other number.

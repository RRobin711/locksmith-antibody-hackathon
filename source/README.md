# `source/` — the organisers' handbook

**Deliberately not in this repository.** This directory held
`antibody-design-hackathon-handbook.pdf` and its text extraction, the brief issued by
Locksmith Bio and IBAB EC. That is their document, and republishing it here is not mine
to do, so it is gitignored.

Nothing in the pipeline reads it at runtime — it is a human reference only. Every
requirement the code depends on was extracted into the repository at
[`docs/sessions/2026-09-14-antibody-hackathon-spec-and-scoring.md`](../docs/sessions/2026-09-14-antibody-hackathon-spec-and-scoring.md):
the scoring formula with worked arithmetic, all eight hard cutoffs, the metric
definitions with units, the submission-format invariants, and the contradictions found
in the handbook itself.

Section references throughout this repository (§4.1, §5.2, §7.2, §9.2, …) are to the
handbook. If you have a copy, drop it back in here; if you don't, the extraction above
is self-contained.
